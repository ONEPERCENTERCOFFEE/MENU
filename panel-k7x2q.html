Menü Yönetimi

Menüyü düzenlemek için GitHub erişim anahtarınızı girin. Anahtar olmadan kimse değişiklik yapamaz.

Erişim anahtarı nasıl alınır?
  1. GitHub'da sağ üstteki profil resmi > Settings.
  2. Sol menüde en altta Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  3. Bir ad verin (örn. menü), süre seçin (örn. 1 yıl).
  4. Repository access: Only select repositories > MENU.
  5. Permissions > Repository permissions > Contents: Read and write.
  6. Generate token deyip çıkan anahtarı kopyalayın ve yukarıya yapıştırın. Bir daha gösterilmez, güvenli bir yere kaydedin.

Değişiklikler yalnızca "Kaydet"e basınca yayına gider.
